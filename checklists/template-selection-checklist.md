# Unity Game Template Selection Checklist

Choosing a Unity template is an important step before starting a reskin or publishing project.

Use this checklist before committing to a template.

## 1. Unity Compatibility

- [ ] Check the Unity version
- [ ] Confirm compatibility with your target platform
- [ ] Open the project successfully
- [ ] Check for console errors
- [ ] Test the main gameplay loop

## 2. Code Quality

- [ ] Scripts are organized
- [ ] Classes have clear responsibilities
- [ ] Important systems are easy to locate
- [ ] No unnecessary duplicate scripts
- [ ] Configuration values are easy to modify

## 3. Assets

- [ ] Asset licenses are clear
- [ ] Source files are available where required
- [ ] Assets can be customized
- [ ] Textures can be replaced
- [ ] Audio can be replaced
- [ ] UI elements can be customized

## 4. Customization

Check whether you can easily change:

- [ ] Game logo
- [ ] App icon
- [ ] Colors
- [ ] UI
- [ ] Characters
- [ ] Environment
- [ ] Sounds
- [ ] Music
- [ ] Gameplay settings

## 5. Mobile Performance

- [ ] Test on a real Android device
- [ ] Check memory usage
- [ ] Check FPS
- [ ] Check draw calls
- [ ] Check texture sizes
- [ ] Check loading times
- [ ] Check battery usage

## 6. Monetization

If monetization is required:

- [ ] Ads can be integrated
- [ ] Rewarded ads can be supported
- [ ] Interstitial ads can be configured
- [ ] Ad placement can be customized
- [ ] Monetization does not interrupt gameplay unnecessarily

## 7. Documentation

- [ ] Installation instructions available
- [ ] Setup instructions available
- [ ] Important systems documented
- [ ] Build instructions available
- [ ] Third-party dependencies identified

## Final Decision

Before selecting the template, ask:

> Can I understand the project, customize it, optimize it, and maintain it after launch?

If the answer is no, the template may create more work than it saves.
