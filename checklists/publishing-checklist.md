# Unity Game Publishing Checklist

Use this checklist before publishing a Unity game created or customized from a game template.

## 1. Project Configuration

- [ ] Correct Unity version confirmed
- [ ] Target platform selected
- [ ] Application identifier configured
- [ ] Product name configured
- [ ] Company or developer name configured
- [ ] Version number updated
- [ ] Bundle version or build number updated

## 2. Gameplay Testing

- [ ] Main menu tested
- [ ] Gameplay tested
- [ ] Pause system tested
- [ ] Restart system tested
- [ ] Game-over flow tested
- [ ] Level progression tested
- [ ] Save/load system tested
- [ ] Reward systems tested

## 3. UI and Branding

- [ ] Game logo updated
- [ ] App icon prepared
- [ ] UI tested on different screen sizes
- [ ] Text is readable
- [ ] Buttons work correctly
- [ ] Loading screens tested
- [ ] Splash screen configured

## 4. Performance

- [ ] Tested on real Android devices
- [ ] Tested on target iOS devices when applicable
- [ ] FPS checked
- [ ] Memory usage checked
- [ ] Draw calls reviewed
- [ ] Texture sizes optimized
- [ ] Audio compression reviewed
- [ ] Loading times tested
- [ ] Build size reviewed

## 5. Monetization

If the game uses monetization:

- [ ] Rewarded ads tested
- [ ] Interstitial ads tested
- [ ] Banner ads tested if applicable
- [ ] Ad placement reviewed
- [ ] In-app purchases tested if applicable
- [ ] Purchase restoration tested where required
- [ ] Ads do not unnecessarily interrupt gameplay

## 6. Analytics

If analytics is integrated:

- [ ] Analytics SDK configured
- [ ] Important events tested
- [ ] Game session tracking tested
- [ ] Ad events tested
- [ ] Purchase events tested
- [ ] Debug/test data reviewed

## 7. Store Assets

Prepare the required store materials:

- [ ] App icon
- [ ] Screenshots
- [ ] Feature graphics where required
- [ ] Promotional images where applicable
- [ ] Store title
- [ ] Short description
- [ ] Full description
- [ ] Keywords or metadata where applicable

## 8. Privacy and Legal Requirements

Review the requirements that apply to the target platform and region.

- [ ] Privacy policy available
- [ ] Third-party SDK requirements reviewed
- [ ] Advertising disclosures reviewed
- [ ] Data collection requirements reviewed
- [ ] Asset licenses reviewed
- [ ] Third-party licenses reviewed
- [ ] Copyright requirements reviewed

## 9. Production Build

Before uploading the final build:

- [ ] Development/debug settings disabled where appropriate
- [ ] Production configuration enabled
- [ ] Release signing configured
- [ ] Version number verified
- [ ] Build number verified
- [ ] Application identifier verified
- [ ] Production ads configuration verified
- [ ] Production analytics configuration verified

## 10. Final Device Test

Install the production build on real devices.

Test:

- [ ] First launch
- [ ] Gameplay
- [ ] UI
- [ ] Audio
- [ ] Ads
- [ ] Purchases
- [ ] Save data
- [ ] Offline behavior
- [ ] Network-dependent features
- [ ] App restart
- [ ] Device rotation if supported
- [ ] Background/foreground behavior

## Final Release Check

Before publishing, confirm:

- [ ] No critical bugs remain
- [ ] No major console errors
- [ ] Performance is acceptable
- [ ] Store assets are ready
- [ ] Privacy information is available
- [ ] Licenses have been reviewed
- [ ] Production build has been tested
- [ ] Final version number is correct
